# Version 0.2 Alpha — Course Management

**Release Status:** Internal Alpha

**Release Date:** August 2026

## Overview

Version 0.2 Alpha expands the platform beyond Quiz and Assignment Management by introducing Course Management capabilities, shared course authorization, and additional project documentation.

## Major Features

### Course Management

- Enable Course Gating
- Disable Course Gating
- Soft Zero Management
- Preview Changes
- Apply Changes
- Detailed execution reporting

### Security

- Accelerate Education course verification
- Shared authorization service
- Automatic verification reset when Course IDs change
- Workspace protection for unauthorized courses

### User Experience

- Redesigned Course Management interface
- Three-state action cards
- Improved Preview and Apply workflow
- Consistent execution summaries

- README
