# Accelerate Canvas Administration Suite

> A modern administration toolkit for Canvas LMS that simplifies repetitive administrative tasks through a secure and intuitive web interface.

## Overview

The Accelerate Canvas Administration Suite is a Streamlit-based administration application designed to simplify common Canvas LMS administrative tasks through an intuitive graphical interface.

Rather than requiring administrators to execute scripts or make repetitive manual changes, the application allows bulk updates to Canvas courses safely using the Canvas REST API.

---

## Current Features

### Dashboard
- Application home screen
- Canvas connection status
- Navigation to administration tools

### Quiz & Exam Management
- Modify quiz settings
- Update attempt limits
- Configure scoring methods
- Shuffle answers
- Show one question at a time
- Student review settings
- Password protection

### Assignment Management
- Bulk assignment updates
- Assignment configuration tools

### Course Management
- Module gating
- Soft Zero
- Due Date Management (In Development)
